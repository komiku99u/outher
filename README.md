# Catatan Onlen

Website link bio sederhana yang dibuat menggunakan HTML dan CSS murni. Berisi kumpulan tautan penting untuk kebutuhan pribadi, catatan, tools, dan berbagai sumber daya yang sering digunakan.

## ✨ Fitur

* Tampilan responsif untuk desktop dan mobile
* Foto profil dan banner cover
* Desain sederhana dan ringan
* Mudah dikustomisasi
* Mendukung favicon
* Siap digunakan di GitHub Pages

## 📂 Struktur Folder

```text
assets/
├── css/
│   └── style.css
├── images/
│   ├── cover.jpg
│   ├── favicon.ico
│   └── yudha.png
└── index.html
```

## 🔗 Daftar Tautan

* Youtube Vanced
* Notes
* Microsoft Activation Scripts (MAS)
* Wallpaper
* POS Database
* Remove.bg

## 🚀 Menjalankan Proyek

1. Clone repository:

```bash
git clone https://github.com/username/repository.git
```

2. Masuk ke folder proyek:

```bash
cd repository
```

3. Buka `index.html` menggunakan browser.

## 🌐 Deploy ke GitHub Pages

1. Upload seluruh file ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pada bagian **Source**, pilih:

   * Branch: `main`
   * Folder: `/ (root)`
4. Simpan pengaturan.
5. Website akan tersedia melalui URL GitHub Pages.
